# cpf-cnpj-core

Validação e geração de dígitos verificadores de CPF/CNPJ (mod-11 da
Receita Federal). Zero dependências, Node >= 22.

Parte do laboratório open source da LOFRANO TECNOLOGIA. MIT.

```sh
npm test          # 8 testes, node:test, sem dependências
npm run demo
```

Somente validade sintática — sem consulta a cadastros. MIT — veja `LICENSE`.
